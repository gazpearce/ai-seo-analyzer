# AI SEO Analyzer

## How to Run on Windows

This application runs directly in your browser. No installation is needed.

1.  **Double-click the `start.bat` file.**

This will open the application in your default web browser (like Chrome, Edge, or Firefox).

---

### Note for Developers

This project uses modern browser features (import maps) and does **not** require a build step or a local server.

**DO NOT RUN `npm install` or `npm run dev`.** These commands are for a different type of project setup and will cause errors.
